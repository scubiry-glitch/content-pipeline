# Moma macOS Installer

One-click installer for macOS that sets up:

- **Node.js LTS** (v18+)
- **Claude CLI** (`@anthropic-ai/claude-code`)
- **Moma plugin** into your Obsidian vault

## Quick start

Double-click **`install.command`** — macOS opens it in Terminal and runs the installer automatically.

> **Note:** You may be prompted for your password to install Node.js (if Homebrew is not available) or to run `npm install -g` in a system-owned prefix.

---

## Distribution modes

### Mode A — Standalone (recommended for distribution)

Place all files in the same folder:

```
install.command
install-moma.sh
main.js
styles.css
manifest.json
```

The installer detects the pre-built plugin files and copies them directly — no build tools needed on the target machine.

### Mode B — Source

Run from inside the repository (e.g. `installer/moma-mac/`). The installer detects `package.json` one level up, runs `npm run build`, then installs the output.

### Mode C — CDN

If neither bundled files nor a source tree are present, the installer downloads the plugin files from the CDN automatically.

---

## Manual invocation

```bash
bash install-moma.sh
```

---

## What the installer does

| Step | Action |
|------|--------|
| 1 | Verifies `python3` is available (built into macOS 12.3+) |
| 2 | Detects Node.js ≥ 18; installs via Homebrew if available, otherwise downloads the official `.pkg` from nodejs.org |
| 3 | Checks for `claude` CLI; runs `npm install -g @anthropic-ai/claude-code` if missing (retries with `sudo` on permission errors) |
| 4 | Checks `/Applications/Obsidian.app` and `~/Applications/Obsidian.app`; warns if not found |
| 5 | Locates pre-built plugin files (Mode A), builds from source (Mode B), or downloads from CDN (Mode C) |
| 6 | Scans `~/Documents`, `~/Obsidian`, and `~/Desktop` for Obsidian vaults |
| 7 | Presents a numbered list if multiple vaults are found; prompts for a path if none are found |
| 8 | Copies `main.js`, `styles.css`, `manifest.json` to `<vault>/.obsidian/plugins/moma/` |
| 9 | Adds `moma` to `community-plugins.json`, disables safe mode, and writes the absolute `claude` binary path to `.moma/moma-settings.json` |

---

## Why the CLI path is auto-configured

Obsidian is an Electron app and launches without a full login-shell environment, so it may not inherit your shell's `PATH`. The installer resolves the absolute path of the `claude` binary and writes it to:

```
<vault>/.moma/moma-settings.json → providerConfigs.claude.cliPath
```

If the path is missing or wrong after installation, set it manually in Obsidian:

```
Moma Settings → Advanced → Claude CLI path
```

To find the path yourself:

```bash
which claude
# → e.g. /opt/homebrew/bin/claude  (Homebrew)
#         /usr/local/bin/claude     (system installer)
```

---

## After installation

1. Open Obsidian (restart if already running)
2. **Settings → Community Plugins → Installed plugins** → enable **Moma**
3. Run `claude` in a terminal to authenticate with your Anthropic API key
