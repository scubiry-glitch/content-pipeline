## 一、美租的定位困境

**与租务团队功能重叠**
- 租务团队（成本中心）已在做包外包内的局改、维修，以成本价给供应商
- 美租被定位为盈利中心，要求有利润——两种逻辑天然冲突
- 如果只做省心租收房标准的局改（刷墙、铺地板），租务就能干，不需要美租

**结论**：纯做局改没有独立存在价值。两年前就已认清这点，转向做品牌方向。

## 二、业务方向：差异化收房品牌

**资源侧不冲突**
- 美租收的房 = 原资管不收的 + 管理团队不管的 + 经纪人不推的
- 跟省心租07的收房画像完全不同，资源层面不竞争

**需要搭建的能力体系**
- 哪些楼盘能收 / 不能收 / 能溢价多少 / 能收多少套
- 整套楼盘筛选与溢价评估体系

**业务逻辑的差异**
- 省心租：跟着市场往下走（2500→2000→1800），收房往下压价
- 美租：往上做，通过装修投入实现溢价

**风险暴露**
- 托管5年做装修投入，最终业主不满意还是会来找贝壳
- 合同上贝壳撇清责任（信托/酒管/供应商追偿），但业主只认贝壳品牌
- 这是"现在就能想得到的"未来风险

## 三、团队搭建：照搬自如体系

**选人策略**
- 大部分挖的自如的人（接触过快装、供应链、材料、工程交付、产品研发）
- 家装公司、地产公司背景的人都不合适
- 逻辑：自如跑了十几年，1:1照搬直接用了，不需要再踩坑

**上海班子**
- 说话人1去年年底过来，4月10日开始上线产品
- 搭建约3个月，基本成型，还缺一些人

**城市差异**

| | 上海 | 成都 |
|---|---|---|
| 主流模式 | 80%全拆改（整装），20%纯软装 | 80%配置，20%全拆改 |
| 客单价 | 高 | 低 |
| 团队需求 | 整装设计能力 | 软装+转化能力 |

## 四、设计师团队改革失败（关键踩坑）

**改革背景**
- 四五月份做了一次改革：拆出UE各环节成本→判断取消设计师团队→压低价格→让资管自己谈

**结果**：试了2个月，彻底失败
- 资管连刷个墙都讲不明白，别说全拆改设计了
- 资管的业绩靠二出（首招+二招出房），不靠收美租的房
- 收8套省心100就能拿最高起点，不会给自己增加难度去推美租

**教训**：不能想当然认为资管有能力/动力去推美租产品。设计师团队不能省，转化需要专业人做。

## 五、关键判断

1. 美租的独立价值 = 品牌溢价能力 + 装修设计转化能力，不是另一支施工队
2. 产品/供应链/工程交付都好解决，真正的问题是**定位和资源分配**
3. 自如团队1:1照搬是目前最务实的路径
4. 后端托管管理（在管2000套 vs 省心租12万套）跟自营逻辑更像，不能套省心租模式
