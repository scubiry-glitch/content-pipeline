# 贵州旅居项目 — 省市区政府沟通进展汇报

## 小结

### 1. 战略合作与协议推进
- **省住建厅**：已明确支持与贝壳集团的合作，但尚未明确由省一级签署协议。省副省长将召开专项座谈会，旨在推动此事，这被视为重大机遇。
- **省文旅厅**：态度积极，可作为备选方案，若住建厅推动受阻，则可由文旅厅主导。
- **贵阳市**：市住建局表示将支持项目落地，并可协助推动贵阳市与贝壳签订具体项目的合作协议。

### 2. 标杆资产与项目筛选
- **资产情况**：经过初步筛选，发现两个潜在的优质资产：一是已装修完毕的贵州日报天眼办公楼；二是毛坯状态的另一栋酒店式建筑。
- **资产画像**：为提高效率，需明确旅居标杆项目和旅居服务中心的资产画像，以便政府方精准匹配。初步画像已形成，待进一步确认。

### 3. 商业模式与产品设计
- **商业模式**：商业模式测算显示具备可行性，预计可实现3000万至9000万的年收入及较高的毛利率。核心竞争壁垒在于贝壳的流量、线下门店及经纪人网络。
- **产品设计**：计划于2025年3月前后上线线上订单闭环功能。C端产品将嵌入贝壳App，但为便于政府推广，需设计去标识化的访问入口。

### 4. 项目组织与资源投入
- **项目决心**：总部及贵阳公司均表现出极高的投入决心。贵阳公司将抽调更多资源，全力投入项目；项目负责人也将减少其他团队的管理负担，全身心投入。
