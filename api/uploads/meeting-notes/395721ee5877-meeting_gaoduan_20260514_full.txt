高端第一次 - 高端租赁业务发展探讨
时间：2026年5月14日 20:01
地点：上海
参会人员：说话人1, 说话人2, 说话人3, 说话人4, 说话人5

核心议题：
1. 高端租赁业务困境与破局方案（1万以上月租金）
2. 商业模式重构，从房源导向转向客户导向
3. 平台核心竞争力的构建与防跳单机制
4. 团队建设与执行落地策略

第一部分：高端租赁业务困境
- 业内存量：北京每月10套，上海每月10多套（2万以上高端需求）
- 收费问题：租客不给中介费，业主承担全部费用（行业惯例）
- 贝壳矛盾：不敢收高端房（租不出去），也租不出去（找不到客户）

第二部分：破局思路
- 方案A：美租第二曲线，独立品牌，独立团队，重新定价
- 方案B：定制化服务，以企业高管为核心客群
- 方案C：平台赋能，通过金融能力+配套服务+不可替代价值锁定客户

第三部分：三层业务架构
1. 底层（房源能力）：贝壳核心优势，点哪都有房
2. 中层（生活配套）：保洁、保姆、司机、律师等一站式服务
3. 上层（平台价值）：金融能力（电佣等）、圈子活动、防跳单钩子

第四部分：具体实施策略
- 小红书霸榜策略：汤臣一品→古北别墅→世纪公园别墅→老洋房
- 每个核心盘配备10个客户经理
- 企业客户优先（公款支出），散客为辅
- 获客渠道：企业人力行政、猎头公司、银行/券商私行客户

第五部分：财务算账
- 高端客户画像：月租2万×12个月=24万，拿出5万装修可提升价值
- 成功标杆：找到100个高净值客户可支撑40亿基金
- 上海市场容量：约200套月租5万以上高端房源

第六部分：团队建设要求
- 客户经理要求：形象气质佳，懂上海高端，不乱发散
- 建议人选：老邵（懂上海，执行强，不乱发散）
- 企业账号而非个人IP（避免离职带走资源）

第七部分：待办清单
1. 说话人1下午充完费，将企业账号变成个人账号
2. 说话人1从零开始学 Cloud Code
3. 说话人2画个图总结养老机构合作相关细节和卡点
4. 说话人1安排客户经理在小红书上对汤臣一品相关内容霸榜
5. 说话人1针对汤臣一品、古北别墅等楼盘组建找客团队

第八部分：风险控制
- 装修回款风险：装修公司可能违规自租以触发回款
- 跳单风险：客户经理脱离平台无法锁定客户
- 客源风险：缺乏获客能力（贝壳强在找房，弱在找客）

第九部分：平台不可替代价值（防跳单钩子）
- 金融能力：电佣、年付转按月等金融产品
- 品牌背书：平台认证的高端服务商形象
- 圈子活动：高端客户交流平台（高尔夫、读书会等）

第十部分：实施节奏
- 第一阶段：单点打盘（汤臣一品霸榜，形成市场占有率）
- 第二阶段：盘子串连（为客户提供上海生活体验路线）
- 第三阶段：平台闭环（建立防跳单机制，形成护城河）

本次会议达成关键共识：
1. 高端租赁需以客户为中心，而非房源为中心
2. 必须建立平台不可替代价值（金融能力为核心）
3. 小红书霸榜策略是低成本获客的有效方式
4. 企业客户是突破口，散客为辅
