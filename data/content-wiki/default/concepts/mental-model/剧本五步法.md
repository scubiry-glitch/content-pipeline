# 剧本五步法

p1 在本场会议提出的总监级规划标准结构:

1. B 点:你想实现一个什么样的结果?(目标)
2. 卡点:最核心的、导致 B 点达成或达不成的问题是什么?
3. 解决方案:你的策略是什么?
4. 确定性评估及应急预案:这套方案确定能达成目标吗?卡壳了 B 计划是什么?
5. 末端行为改变:经纪人/资管 56789 月相比 1234 月,哪些末端行为发生了变化?(且这变化是由你设计的)

p1 用「拍电影 = 剧本 + 拍摄 = 操作手册 + 末端行为」的隐喻强调:写得再精彩也需要去拍摄,拍摄就是末端行为变化。
