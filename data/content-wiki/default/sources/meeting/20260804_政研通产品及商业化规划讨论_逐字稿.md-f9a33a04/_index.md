## 二、主要张力 · Tensions

### T1 · 口径对齐 vs 快速扩城对外
当事人: [[领导]] / [[刘安]] · 强度: 0.55

本场第一个议题就卡在口径上。p1 的立场是: 对外交付前内部口径必须先对齐, 否则 8 城、40 城的指数对外放出去就是自砸招牌——他连续追问「成交指数跟成交价指数，这两个指数是什么呀？」，并直接点破「我们现在不确定你那个一不一致，对吧？」。p3 的立场是: 这批指数就是跟陶老师、杨总一起搞的三个指数, 基准就是 24 年 1 月定基, 他反复确认「对对对对，我们都是有24年，对，我印象中，1月份开始做定期的」，但也承认「这个好像是不是的。不是24年1月定基？你合一下吧，合一下」——即他自己也不能 100% 肯定, 需要合数验证。p2 夹在中间补数据周期「现在是给了3年，现在整个数据周期给的是2024年1月份开始的」。张力在于: 一边是 8 城已上线、12 城在途、40 城在计划的扩张节奏, 一边是连定基基准都还没核实的口径悬置; p1 用「你自己内部口径先一致」把球踢回给 p3, p3 用「你合一下吧」接住, 但没有形成结论, 只能等合数后到下周一评审见分晓。

- p1:「成交指数跟成交价指数，这两个指数是什么呀？」
- p3:「这个好像是不是的。不是24年1月定基？你合一下吧，合一下。那现在这个基准取取得有点多。」
- p1:「我们自己内部口径先一致。那你现在不确定你那个一不一致，对吧？」
- p3:「对对对对，我们都是有24年，对，我印象中，1月份开始做定期的。」

### T2 · 专家蒸馏的授权边界: 改名即用 vs 无授权不敢对外
当事人: [[产品负责人]] / [[领导]] · 强度: 0.65

专家蒸馏的合规边界是全场最有火药味的一段。p2 的立场是审慎: 他抽过老左、高善文等一批专家, 但「没有，他自己用，不敢对外」, 因为无授权只能内部自用——关键认知、方法论、心智模型都抽了出来, 却不敢产品化。p1 的立场是实用主义: 「哎，那咱就用啊。你不用，你抽了。」他给出的解法是改名——「高善文。你这是要审，你那个，你把这名都改了」, 用「高博士」「杨博士」「刘博士」代替真名。p3 一句「我整了。这有个阴谋」表明他早就在做改名处理, 三人就此达成默契「行行行。那高善文，你就用」。张力在于: 真名背后的肖像权与署名权并不会因为改名而消失, p2 的「不敢对外」与 p1 的「那咱就用啊」之间的推拉没有真正解决, 只是被「改名+内部自用」暂时压住。

- p2:「没有，他自己用，不敢对外。对，他的关键认知，他的方法论，他的心智模型。」
- p1:「哎，那咱就用啊。你不用，你抽了。高善文。你这是要审，你那个，你把这名都改了。」
- p3:「我整了。这有个阴谋。」
- p1:「你把你把名改了。行行行。那高善文，你就用。」

### T3 · 按次低价走量 vs 按 token 高价包装
当事人: [[领导]] / [[产品负责人]] · 强度: 0.4

p1 一开始的直觉是走量: 「1000次一块还是几……千次调用，一毛还一块，我们定个价」, 在他看来数据准就是硬道理「那我是最准的」。p2 立刻纠正: 「咱也不按次，咱也按 token，咱也包装一下」, 理由很直白「按次太便宜了。按 token 贵」。p1 很快被说服「也按 token，那还可以」。两人都没有量化市场规模, 全凭直觉; 12 元/年的 toC 包月订阅与按 token 的 toB 定价并存, 两个价格体系之间的定位矛盾并没有被讨论清楚。

- p1:「假如说什么，1000次一块还是几，对吧？你就是千次调用，是吧？一毛还一块，我们定个价，是吧？他能承受，是吧？那我是最准的。」
- p2:「咱也不按次，咱也按 token，咱也包装一下。」
- p2:「按次太便宜了。按 token 贵。可以可以。」
- p1:「也包月，对吧？一年12块钱，是吧？哇，那你就随便问他」

### T4 · 抢版权窗口期全量清洗 vs 有选择地洗避肖像红线
当事人: [[领导]] / [[产品负责人]] · 强度: 0.45

p1 判断现在正处版权真空期: 「因为他现在呀，现在是免费的。对对对。没有版权。嗯，对。接下来保证都有版权」, 所以必须抢在版权收紧之前把居住行业内容全部清洗入库, 行动指令是「你明天搞个系统。安排个人……行业的内容全洗掉。进库」, 理由是「未来肯定值钱」。p2 补了一句冷水「那脸还有个版权，这个风格可没版权」——脸和名字有肖像权, 风格没有。p3 举了张雪峰数字人的例子说明这事大家早就在干。张力在于: p1 想全量快洗、赌版权窗口, p2 想有选择地洗、避开肖像权红线; 最终 p1 的指令被执行, 但筛选规则没有定下来。

- p1:「假如他把他把那个过去10年还是5年，就是抖音上的这些人的视频。全洗了。」
- p1:「他就是未来就是这个值钱，你知道吗？对。因为他现在呀，现在是免费的。对对对。没有版权。嗯，对。接下来保证都有版权，你知道吗？」
- p2:「那脸还有个版权，这个风格可没版权。」
- p1:「你明天搞个系统。安排个人，你知道吗？就是洗这个，把这个行业的所有的。行。那个跟居住相关的。行业的内容全洗掉。进库。」

### T5 · 客户重心: 开发商/住建渠道 vs 银行等有钱的客户
当事人: [[领导]] / [[产品负责人]] · 强度: 0.5

p1 最初的设想是把指数卖给开发商: 「一旦我这个渠道建立之后，让顾晓佳找开发商也是，是吧？那我就有开发指数」。p2 泼了冷水: 「开发商的钱反而不好挣，开发商算的贼细」, 并举了定价咨询对比: 福州一套房 2000 元「我觉得挺贵了」, 萧山环投「人家说200万、300万都行」。p1 迅速接受并升级成原则: 「他没钱，咱一定要找找有钱的，他现在穷人」。p3 补充「银行其实是很大的客户，在这个领域里面」, p2 收尾「就两类金融市场，一个叫证券，一个叫不动产」。这条张力以快速收敛结束, 但开发商的开发指数、渠道价值仍然挂在产品线上, 只是优先级被降了。

- p1:「一旦我这个渠道建立之后，让顾晓佳找开发商也是，是吧？那我就有开发指数。」
- p2:「就开发商的钱反而不好挣，开发商算的贼细。」
- p1:「他没钱，咱一定要找找有钱的，他现在穷人。对。对。穷人就别别别别别。」
- p2:「我那个福州那个项目，当时他们说一套房子2000，我觉得挺贵了，后来那个咱那个跟肖总去的萧山环投，人家说200万、300万都行。」

### T6 · 要不要收科瑞(克而瑞)
当事人: [[领导]] / [[产品负责人]] · 强度: 0.35

p1 的思路是打包收购补全产品版图: 「那咱就把谁？科瑞也收了吧」, 还拉上老丁的普瑞「没啥值钱的了，也没事，可以让老丁进来」。p2 直接质疑标的价值: 「科瑞是不是也没什么前途现在？」, 并认为新公司本来就不缺它「其实这事有他没他都能做，因为大家看新的是贝壳嘛」。p1 还回忆了当年没投普瑞、周鑫挖人结仇的旧事「那周鑫反正也跟我们结仇，就算了」。收购与否没有拍板, 但 p2 的「有他没他都能做」给 p1 的收购热情降了温。

- p1:「那咱就把谁？科瑞也收了吧。」
- p2:「科瑞是不是也没什么前途现在？」
- p1:「没啥值钱的了，也没事，可以让老丁进来。是，老丁。老丁他自己做了一个公司嘛。」
- p2:「其实这事有他没他都能做，因为大家看新的是贝壳嘛。」
